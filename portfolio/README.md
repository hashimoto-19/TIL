# 自己紹介サイト

開発者の名刺であり、学習の入り口でもある自己紹介サイト。
ポートフォリオに加えて、台湾華語の学習、旅行、山登りの写真も載せられるようにする。

## 概要

GitHub Pages で公開する自己紹介サイトを作成します。
URL を共有すれば、仕事・学習・趣味までひと通り伝えられるようにします。

ただの名刺ではなく、次の 4 つが見えるページにします。

- **開発**: React を中心にした学習と制作物
- **台湾華語**: いま勉強していること
- **旅行**: 行った場所の写真とメモ
- **山登り**: 登った山の写真

## デザイン

### コンセプト

Apple っぽいミニマルな印象。余白を活かして、写真と文章が落ち着いて読めるデザイン。
旅行・山の写真が主役になれるように、装飾は少なめ、タイポグラフィと余白で整える。

キーワード: ミニマリズム / 写真が映える余白 / ナチュラル

### 配色

山と空をイメージした、落ち着いたグリーン系。

- 背景: `#f7f6f3`（温かみのあるオフホワイト）
- テキスト: `#1d1d1f`（読みやすい濃いグレー）
- アクセント: `#2f6f5e`（山の緑）
- サブ: `#5c6b73`（空や岩のグレー）

ダークモード（あると嬉しい）:

- 背景: `#1c1c1e`
- テキスト: `#f5f5f7`
- アクセント: `#6aae97`

### 参考

- [Apple](https://www.apple.com/jp/) — 余白、写真の大きさ、タイポグラフィ
- [Vercel](https://vercel.com/) — 開発者らしいシンプルさ（ダークは参考程度）

## ページ構成（案）

1. **Hero** — 名前、ひとこと自己紹介
2. **About** — いま学習していること（React / 台湾華語）
3. **Skills** — 使える技術
4. **Works** — ポートフォリオ
5. **Taiwanese** — 台湾華語の学習メモ
6. **Photos** — 旅行・山登りのギャラリー
7. **Links** — GitHub などのリンク
