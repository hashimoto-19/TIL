# 自分用学習フロー 🐸

前提: **誰かの反応があると頭に残りやすい**  
→ 「一人で完結」より「出す → 反応を得る」を短く回す。

## 学習の５ステップ

### ❶ インプット（短く）

- React / JS を 10〜30 分だけやる
- 「今日わかったこと・わからなかったこと」を 1〜3 行メモ

### ❷ 作業中ログ → 反応をもらう場所へ

- つまずき・疑問をそ
  のまま出す（完璧な文章にしない）

- 置き場の例:
  - GitHub Discussions（質問・作業ログ）
  - X（短い学び or 「ここわからない」）
  - Cursor / メンターに「これ合ってる？」と聞く

- 目的は正解集めより **反応で記憶にフックをかけること**

### ❸ 学習後にまとめる（TIL）

- `TIL/2026/` の月別 or カテゴリに、反応もらった内容も含めて残す
- 書く型（短くでOK）:
  1. 何がわからなかったか
  2. 誰か（or AI）の反応で何が変わったか
  3. 自分の言葉での結論

### ❹ 小さな成果物を出す

- ミニアプリをこまめに公開（GitHub）
- 「できた画面 / 詰まった点」を Discussions か X に貼る
- 反応があると次の改善が続きやすい

### ❺ 月1振り返り

- TIL に「今月の反応が多かった学び TOP3」を書く
- 転職目標（来年2月）に向けて、次月のテーマを1つだけ決める

## このフローのコツ（自分用）

| コツ           | やり方                                             |
| -------------- | -------------------------------------------------- |
| シンプルに     | 毎日は「学習 → 1投稿（疑問でも可）→ TIL 1行」まで  |
| 反応を設計する | 独りノートで終わらせない。必ず1か所に出す          |
| 可視化         | GitHub コミット + Discussions/X の投稿が進捗になる |
| 柔軟に         | 忙しい日は ❷ の「1行質問」だけでもOK               |
| 楽しむ         | 「教える側の反応」をゲーム感覚で集める             |

## 今の目標とのつなぎ

- 短期: React 基礎 → ミニアプリ → ポートフォリオ
- 定着の弱点（AI頼り・モチベ）は、**外に出して反応をもらう**ことで補う
- Must の「毎日コミット」「10分学習」はそのまま。プラスで **反応導線を1本** 足す
