GitHub Pages へデプロイする設定のまとめです。教材の手順と、あなたの hashimoto-19.github.io のやり方をあわせて整理します。

全体の流れ
コードを書く
→ GitHub に push
→ GitHub Actions がビルド
→ GitHub Pages が公開
→ https://ユーザー名.github.io/ で見られる
React（Vite）は静的ファイル（dist/）にしてから公開します。その自動化が GitHub Actions です。

1. リポジトリを用意する
   種類 リポジトリ名 URL 例
   個人サイト
   ユーザー名.github.io
   https://hashimoto-19.github.io/
   プロジェクトサイト
   任意の名前
   https://ユーザー名.github.io/リポジトリ名/
   あなたは 個人サイト（hashimoto-19.github.io）です。

2. vite.config.js に base を設定
   個人サイト（ユーザー名.github.io）の場合：

import { defineConfig } from "vite";
import react from "@vitejs/plugin-react";
export default defineConfig({
base: "/",
plugins: [react()],
});
プロジェクトサイト（教材の書き方）の場合：

export default defineConfig({
base: process.env.GITHUB_PAGES ? "/REPOSITORY_NAME/" : "./",
plugins: [react()],
});
REPOSITORY_NAME は実際のリポジトリ名に置き換えます。
※ 個人サイトでは base: "/" で OK です。

3. GitHub Actions のワークフローを作る
   ファイル例: .github/workflows/deploy.yml（教材だと deploy-gh-pages.yml）

   左メニュー Pages
   Build and deployment の Source を GitHub Actions にする
   （教材どおり。Deploy from a branch ではなく GitHub Actions が正しい）

1. Reactの基本用語一覧
最初は、この表にある用語を理解することを目標にしてください。
用語	意味	簡単な例・イメージ
React	UIを作るJavaScriptライブラリ	Web画面を作る道具

Component（コンポーネント）	画面を構成する部品	ボタン、ヘッダー
Props（プロップス）	親から子に渡すデータ	ボタンに表示する文字
State（ステート）	コンポーネントが管理する状態	カウンターの数字
useState	Stateを扱うためのフック	数字を増やす

Event（イベント）	ユーザーの操作などで発生するもの	クリック、入力

まず理解したい5つの用語









① コンポーネント（Component）
画面を部品ごとに分けて作る考え方です。例えば、ヘッダー、商品カード、ボタンをそれぞれ部品にします。
キーワード：部品化・再利用












② Props（プロップス）
部品に外からデータを渡す仕組みです。例えば、同じボタン部品に「保存」「削除」という別々の文字を渡せます。
キーワード：親から子へのデータ受け渡し












③ State（ステート）
画面の中で変化するデータです。例えば、ボタンを押すたびに数字が1増える仕組みです。
キーワード：変化するデータ












④ イベント（Event）
ユーザーの操作をきっかけに処理を実行します。クリックや入力などが代表例です。
キーワード：操作のきっかけ












⑤ useEffect
APIからのデータ取得など、画面表示以外の処理を扱うフックです。基本のStateやイベントを理解してから学ぶとスムーズです。
キーワード：外部との連携・副作用



2. JSX・JavaScriptで使う用語
Reactのコードを読むには、JavaScriptの用語も必要です。
用語	意味
変数（Variable）	データを入れておくもの
定数（const）	再代入できない変数の宣言
関数（Function）	処理をまとめたもの
アロー関数（Arrow Function）	() => {} の形式で書く関数
引数（Parameter / Argument）	関数に渡すデータ
戻り値（Return Value）	関数が返すデータ
配列（Array）	複数のデータを並べたもの
オブジェクト（Object）	名前と値を組み合わせたデータ
分割代入（Destructuring）	配列やオブジェクトから値を取り出す記法
テンプレートリテラル	`こんにちは${name}` のように文字列を組み立てる記法
import / export	ファイル間で機能を読み込む・公開する仕組み
return	関数から値を返す
if / 三項演算子	条件によって処理や表示を分ける
map()	配列の各要素を変換する
filter()	条件に合う要素を取り出す
async / await	非同期処理を扱いやすく書く記法
例えば、次のコードです。
function Welcome({ name }) {
  return <h1>こんにちは、{name}さん</h1>;
}


この短いコードにも、複数の用語が出てきます。
- function：関数を定義する
- Welcome：コンポーネント名
- { name }：Propsの分割代入
- return：表示する内容を返す
- <h1>：JSXで記述した要素
- {name}：JavaScriptの値をJSX内に埋め込む
コードを読めるようになるには、1行の中にある用語を分解して理解するのが効果的です。
