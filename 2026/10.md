# React用語集

## 1. Reactの基本用語

- React：Web画面を作るためのJavaScriptライブラリ
- JSX：JavaScript内にHTMLに似た記法を書く仕組み
- Component（コンポーネント）：画面を構成する部品
- Props（プロップス）：親コンポーネントから子に渡すデータ
- State（ステート）：コンポーネントが管理する状態やデータ
- useState：Stateを扱うためのReact Hook
- Hook（フック）：Reactの機能を関数コンポーネントなどから利用する仕組み
- Event（イベント）：クリックや入力などの操作
- onClick：クリック時のイベントハンドラー
- onChange：入力値などが変化したときのイベントハンドラー
- Render（レンダー）：Reactが画面の表示内容を計算すること
- return：関数から値を返す構文

## 2. JavaScriptの基本用語

- 変数（Variable）：データを保持するもの
- const：再代入できない変数を宣言する構文
- Function（関数）：処理をまとめたもの
- Arrow Function（アロー関数）：() => {} の形式で書く関数
- Parameter（仮引数）：関数が受け取る値の名前
- Argument（実引数）：関数を呼び出すときに渡す値
- Return Value（戻り値）：関数が返す値
- Array（配列）：複数のデータを並べたもの
- Object（オブジェクト）：名前と値を組み合わせたデータ
- Destructuring（分割代入）：配列やオブジェクトから値を取り出す記法
- Template Literal：バッククォートで文字列を組み立てる記法
- import：別のファイルなどから機能を読み込む構文
- export：別のファイルなどから利用できるように公開する構文
- if：条件によって処理を分ける構文
- Ternary Operator（三項演算子）：条件に応じて2つの値から選ぶ記法
- map()：配列の各要素を変換するメソッド
- filter()：条件に合う要素を取り出すメソッド
- async / await：非同期処理を扱いやすくする構文

## 3. JSX・画面表示の用語

- Conditional Rendering（条件付きレンダリング）：条件に応じて表示を切り替えること
- Logical AND（&&）：条件が成立するときに表示するなどの処理に使う演算子
- key：リスト内の要素をReactが識別するための値
- Fragment：余分なHTML要素を追加せずに複数要素をまとめる仕組み
- children：コンポーネントのタグの中に渡す内容
- Truthy / Falsy：条件式で真・偽として扱われる値

## 4. データ取得・状態管理の用語

- useEffect：外部システムとの同期などを扱うHook
- fetch：APIなどからデータを取得するための機能
- API：アプリやシステム同士がデータをやり取りする窓口
- HTTP Request：サーバーへのリクエスト
- HTTP Response：サーバーからのレスポンス
- JSON：データを表現する形式
- Promise：非同期処理の結果を表すオブジェクト
- 非同期処理：完了を待つ間にほかの処理を進められる処理
- Loading：読み込み中の状態
- Error Handling：エラー発生時の処理
- Custom Hook（カスタムフック）：ReactのHookを使ったロジックを再利用する仕組み
- Context：コンポーネント間でデータを共有する仕組み
- State Management（状態管理）：アプリのデータの状態を管理すること

## 5. TypeScript・開発環境の用語

- TypeScript：JavaScriptに型システムを加えた言語
- Type（型）：データの種類や構造を表すもの
- type：型の別名などを定義する構文
- interface：オブジェクトなどの型の形を定義する構文
- Type Inference（型推論）：型を自動的に推測すること
- Type Error（型エラー）：型のルールに合わないことによるエラー
- npm / pnpm：パッケージ管理ツール
- package.json：プロジェクトの設定や依存関係を記述するファイル
- Vite：開発サーバーやビルドを支援するツール
- Next.js：ReactをベースにしたWeb開発フレームワーク
- ESLint：コードの問題やルール違反を検出するツール
- Git：ソースコードの変更履歴を管理する仕組み
- Pull Request（PR）：変更内容をレビューして取り込んでもらうための仕組み
