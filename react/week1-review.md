## React 学習 初週の振り返り

### やったこと

- React 学習の全体計画を確認
- JavaScript での DOM 操作の基礎を確認
- React の基本的な使い方と JSX 記法を学習
- コンポーネントの設計原則を理解
- Props によるデータ受け渡しを学習
- useState Hook を使った状態管理を体験

### 新たに得た学び

- コンポーネント化する理由などが知れた
- 理解するのが大変で、reactで制作したほうが楽そうだなと感じることができモチベーションにつながった。
- JSX 記法の便利さと、コンポーネント思考の重要性を実感
  - 再利用可能なコンポーネントを作成する楽しさ
- Props と State の違いを理解できた
  - Props: 親から子へのデータ受け渡し
  - State: コンポーネント内部の状態管理

### 感想や今後の改善点

- 実際に手を動かしてコードを書くことが、理解を深めるのに効果的だった
- 次週からは、より実践的なプロジェクト制作に入っていくので楽しみ
- わからない部分は、すぐに Discord で質問できる環境が整っているので活用したい
