## React 学習 初週の振り返り

### やったこと

- React 学習の全体計画を確認
- JavaScript での DOM 操作の基礎を確認
- React の基本的な使い方と JSX 記法を学習
- コンポーネントの設計原則を理解
- Props によるデータ受け渡しを学習
- useState Hook を使った状態管理を体験
- 条件付きレンダリング（三項演算子 / `&&`）を学習
- コンポーネントのネスト・コンポーネントツリーを確認
- コンポーネントは関数であること、大文字で書くルールを確認

### 新たに得た学び

- コンポーネント化する理由などが知れた
- 理解するのが大変で、reactで制作したほうが楽そうだなと感じることができモチベーションにつながった。
- JSX 記法の便利さと、コンポーネント思考の重要性を実感
  - 再利用可能なコンポーネントを作成する楽しさ
- Props と State の違いを理解できた
  - Props: 親から子へのデータ受け渡し
  - State: コンポーネント内部の状態管理
- 条件付きレンダリングは「条件が真のときだけ画面に出す」こと
  - 三項演算子: `{isLoggedIn ? <Dashboard /> : <Login />}`
  - `&&`: `{isError && <p>エラーです</p>}`
- コンポーネントはレゴブロックのように組み合わせて大きな UI を作る
  - 更新が必要なときは、そのコンポーネントだけを更新できる
- 設計原則: 単一責任 / 再利用性 / 合成可能性 / UI とロジックの分離
- React コンポーネント名は大文字始まり（HTML タグと区別するため）

### 感想や今後の改善点

- 実際に手を動かしてコードを書くことが、理解を深めるのに効果的だった
- 次週からは、より実践的なプロジェクト制作に入っていくので楽しみ
- AI に頼りすぎると定着しにくいので、自分の言葉でメモして反応をもらいながら覚える
- useEffect や実践的な Hooks、小さなアプリ制作に進みたい
